## Production & Implementation Notes

1. **Vignette Overlays:** All video and visual backdrops must be paired in HTML/CSS with a dark gradient overlay (`linear-gradient(180deg, rgba(10,10,12,0.4) 0%, rgba(10,10,12,0.85) 100%)`) to maintain WCAG AA contrast for text overlays.
2. **Video Compression & Optimization:** Video files (`.mp4`) should be encoded with H.264 / AAC, 1080p target resolution for web delivery, `<video autoplay muted loop playsinline>` attributes.
3. **Scrubbing Mechanics:** `#2 Signature 360° Orbit Video Scrub` is bound directly to GSAP ScrollTrigger timeline scrubbing using `video.currentTime = progress * video.duration`.
